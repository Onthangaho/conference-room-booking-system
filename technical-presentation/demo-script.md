# Demo Script
Conference Room Booking System – API & Contract Overview

This demo is structured as if presented live to a technical audience.

---

1. Open the GitHub repository in the browser.
   This shows the project context and documentation-first approach.

2. Open the README.md file.
   This reinforces onboarding and explains where key artefacts are located.

3. Navigate to the OpenAPI specification file.
   This shows how the API is documented.

4. Open the OpenAPI file in Swagger Editor or Swagger UI.
   This visually shows the available endpoints and request/response formats.

5. Highlight one endpoint, such as GET /rooms.
   Explain parameters and expected responses.

6. Open Postman.
   Import the OpenAPI specification.

7. Show the generated Postman collection.
   This proves the contract can be used for testing.

8. Run a simple GET request.
   Show the response and passing test.

What the demo proves:
- The API contract is clear and usable.
- The system can be tested without a running backend.
- Documentation supports developer onboarding and validation.
